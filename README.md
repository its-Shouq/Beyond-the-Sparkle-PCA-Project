
# 💎 Beyond the Sparkle — Diamond Clustering Analysis

## 📌 Project Overview

This project explores patterns in the Diamonds dataset using **Unsupervised Machine Learning**.

We applied **K-Means** and **DBSCAN** and compared their results before and after dimensionality reduction using **Principal Component Analysis (PCA)**.

## 📁 Project Contents

### 📓 1. Jupyter Notebook
The complete data science workflow:
- Data Cleaning and EDA
- Feature Scaling
- K-Means and DBSCAN Clustering
- PCA Dimensionality Reduction
- Model Evaluation and Comparison

An interactive HTML presentation

## 📈 Key Findings

- **K-Means:** Identified two interpretable diamond clusters.
- **PCA:** Reduced six features to two components while preserving **88.12% of the variance**.
- **DBSCAN:** Identified density-based patterns and noise points.
